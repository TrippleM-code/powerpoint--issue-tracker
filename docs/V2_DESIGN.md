# V2 Alpha.3 Layout

## Header
`[Equal party/logo cells][Issue ID + Area Code][Created / Updated Date-Time]`

- Every party in the party library receives an equal share of the logo area.
- Issue ID and Date-Time sit directly beside the logo area.
- Created is always shown.
- Updated appears only after a meaningful change.

## Main layout
`[Issue Description][Vertical Room / Space][Reference Images][Actions]`

Reference Images is intentionally manual.

## Actions
Columns:
1. Action By
2. Action Required
3. Status

The usable action height is divided equally by the number of actions.
No blank action rows are created.

## Visual rules
- Clean modern layout.
- No rounded action cards.
- Avoid unnecessary outer borders.
- Use line shapes for structural separators.
- Status uses colored text/underline rather than a rounded badge.
