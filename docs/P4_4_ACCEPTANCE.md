# P4.4 Acceptance Checklist

## Party Settings UI
- [ ] each party is one clean card
- [ ] Up / Down controls remain aligned
- [ ] logo preview and party name remain aligned
- [ ] logo actions do not overlap the party name
- [ ] Remove Party occupies a dedicated full-width action row

## One Issue ID per slide
- [ ] blank slide allows a new Issue ID
- [ ] once saved, Issue ID becomes read-only on that slide
- [ ] changing description/area/room/actions under the same ID is allowed
- [ ] Create / Refresh under the same ID is allowed
- [ ] a different Issue ID on an existing issue slide is blocked
- [ ] a new Issue ID requires a new blank slide

## Summary placement
- [ ] Generate / Refresh Summary deletes only previous generated summary slides
- [ ] dashboard becomes slide 1
- [ ] register page 1 becomes slide 2
- [ ] subsequent register pages follow
- [ ] issue slides follow after summary pages
