# V2 Alpha Acceptance Tests

- V1.4.1 can remain installed while V2 Alpha is installed separately.
- New V2 issue can be assigned a unique Issue ID.
- Duplicate Issue IDs are rejected.
- Description saves and Created date remains stable.
- Updated date changes only when structured Issue/Action data changes.
- Create / Refresh Sheet generates a clean structured issue layout.
- Manual images placed in Reference / Images area survive refresh.
- Add, edit and remove actions work.
- Party and Status libraries can be extended.
- Used Party/Status values cannot be removed without first reassigning actions.
- Overall issue status is derived correctly.
- Dashboard regenerates without duplicate generated slides.
- Register groups repeated Issue ID and Description across multiple action rows.
- Large registers paginate.
- Validation reports missing descriptions and invalid action data.
