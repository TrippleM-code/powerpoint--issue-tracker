# Project Goal

Build a production-quality PowerPoint Office Add-in named IssueFlow.

## Problem

Coordination issues are often managed in PowerPoint using manually formatted slides, which causes:
- duplicated data
- inconsistent status tracking
- unclear ownership
- repetitive formatting
- weak summary reporting
- broken links between issue pages and registers

## Target users

- BIM / VDC teams
- MEP coordinators
- design managers
- project managers
- consultants
- contractors
- coordination meeting teams

## Recommended solution

IssueFlow creates a structured issue sheet while preserving PowerPoint freedom for manual reference images and annotations.

Each issue contains:
- Issue ID
- Area Code
- Room / Space
- Description
- Created At
- Updated At
- Actions[]

Each action contains:
- Action ID
- Action By
- Action Required
- Status

## Non-goals for Production V1

- cloud database
- real-time multi-user backend
- AI-generated issue decisions
- automated image editing
- replacing PowerPoint editing tools
