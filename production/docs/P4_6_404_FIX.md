# P4.6 404 Fix

The P4.5 add-in started but Vercel returned 404 for `/p4-5.html`.

P4.6 removes that fragile dependency. The manifest now points to the known-good deployed root entry:

`https://powerpoint-issue-tracker.vercel.app/index.html?v=p4.6`

A fresh add-in ID is still used, so PowerPoint treats it as a new development add-in.
